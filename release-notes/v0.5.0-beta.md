## Nebsty Planner 0.5.0 베타

첫 베타 버전입니다. 써 보시고 [Issues](https://github.com/yang83/nebsty-planner/issues) 에 의견을 남겨 주세요.

**⬇︎ 받기:** 아래 Assets 의 `Nebsty-Planner-0.5.0-beta.dmg`
**필요:** macOS 13 이상 · Apple Silicon / Intel
**사용 기간:** 이 베타는 빌드한 날부터 30일 동안 쓸 수 있습니다. 기간이 끝나도 데이터는 그대로 남습니다.

### 설치
1. DMG 를 열고 Nebsty Planner 를 Applications 폴더로 끌어다 놓기
2. 처음 열 때 경고가 뜨면 **시스템 설정 › 개인정보 보호 및 보안 › "그래도 열기"** (공증 전 베타라서 한 번 필요합니다)

### 들어 있는 것
- **탑다운 플래너** — 사명 · 장기 목표 → 연간 → 월간 → 주간 → 일간, 펼친 노트 화면 (⌘1–8)
- **시간표** — 끌어서 일정 만들기 · 옮기기 · 길이 조절, 할 일을 끌어 타임블록
- **습관 · 반복 일정**, 주간 습관 체크
- **메모 · 프로젝트** — Markdown 문서, WBS 일정표와 간트, 엑셀 붙여넣기
- **Apple 미리 알림 · 캘린더 동기화** — 오늘 마감인 할 일과 일정. 미리 알림 목록 · 캘린더 ↔ `#태그`, 태그 없으면 인박스 · 기본 캘린더
- **구독 캘린더 (ICS)** — 공휴일 · 학교 · 팀 캘린더를 읽기 전용으로 표시
- **이미지** — 메모 · 일간 노트 · 프로젝트 문서에 끌어다 놓기 / 붙여넣기, 모서리를 끌어 크기 조절
- **백업 · 연말 정리**, 데이터 폴더 바꾸기 (iCloud · Nextcloud)
- **글꼴 선택**, 주간/야간 모드, 한국어 / English
- 업데이트 알림

### 알려진 점
- 베타는 아직 Apple 공증 전이라 처음 한 번 "그래도 열기" 가 필요합니다.
- 새 베타로 바꿀 때 미리 알림 · 캘린더 권한을 다시 물을 수 있습니다.
- 반복 일정은 Apple 캘린더 동기화에서 가져오지 않습니다 (구독 캘린더에서는 표시됨).
