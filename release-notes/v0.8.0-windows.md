## Nebsty Planner 0.8.0 for Windows

The first Windows release. It's free, with every feature open (color themes, accent colors, custom fonts, unlimited projects).

**⬇︎ Download:** `Nebsty-Planner-0.8.0-Setup.exe` under Assets below (or the `.zip` if you'd rather not install)
**Requires:** Windows 10 or 11 (64-bit) · Microsoft Edge WebView2 Runtime (built into Windows 11)

### Install
1. Run `Nebsty-Planner-0.8.0-Setup.exe`. No administrator rights are needed; it adds a Start menu shortcut.
2. The installer isn't code-signed yet, so Windows may show **"Windows protected your PC"**. Click **More info › Run anyway**.
3. On first launch your planner data goes to `Documents\Nebsty Planner`. You can move it to any folder (Nextcloud, OneDrive, …) in ⚙ Settings.

Using the zip instead: unzip it anywhere and run `Nebsty Planner\Nebsty Planner.exe`.

### Good to know
- **Same files as the Mac app.** Every page is a Markdown file. Put the data folder in Nextcloud or OneDrive and open the same planner on a Mac and a Windows PC.
- **Sync:** Google Tasks & Google Calendar work on Windows (⚙ Settings › External sync). Apple Reminders & Calendar are Mac-only.
- **Shortcuts use Ctrl** instead of ⌘: Ctrl+1–8 for tabs, Ctrl+E for the Markdown source, Ctrl+D for the theme, Ctrl+, for Settings.
- **Updates:** the app checks this page once a day and tells you when a new version is out.
- If WebView2 is missing (some Windows 10 PCs), the planner opens in your browser and shows where to install it.

### Known issues
- Google sign-in may show a "Google hasn't verified this app" screen. Click **Advanced › Go to Nebsty Planner**.
- Recurring events are not imported by calendar sync (they do show from subscribed calendars).

Please report bugs in [Issues](https://github.com/yang83/nebsty-planner/issues) with your Windows version and a screenshot.
